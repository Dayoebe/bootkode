# Unify BootKode journeys and secure learning, payments and operational workflows

BootKode used competing discovery/account/learning/finance patterns, while sensitive operations relied on menus or client state. The changes establish shared theme tokens and accessible Blade controls, add public published-course discovery, prioritize continue-learning, simplify account forms and standardize finance, careers, community and template-management surfaces.

Registration rejects privileged roles; administrative requests check access. Enrollment cannot bypass payment, and funding/refunds use verified, atomic, replay-safe boundaries. Credential requests recalculate eligibility and remain learner-scoped. Forward migrations preserve certificate history, add saved certificate designs and correct career foreign keys that incorrectly targeted the queue table. Issued designs use snapshots so future edits do not restyle historical credentials.

Career applications recheck public availability, persist with their counters atomically, keep new résumés private and exclude other applicants from discovery. Community moderation guards private reads/mutations and code submissions no longer receive fabricated scores. Job-detail and challenge controls now invoke their real workflows. Explicit offline packs remain supported while private course HTML is excluded from implicit caching. Existing roles, records and functional domains are retained.

Institutions use scoped membership and explicit recipient acceptance without global role escalation. Marketplace checkout, commissions, refunds and invoices use matching funded ledger movements, atomic rollback, currency checks and replay protection; paid files use owner-authorized private delivery. Listing uploads persist and survive edits. Mentorship completion transfers existing funds, and participant/verified-search/mentor-only boundaries apply on each request. Shared headers, bounded navigation, actual profile controls and persistent action feedback extend into these domains.

Support and feedback now recheck staff/owner scope, persist real responses and privately store new attachments. Messaging polling cannot mutate another participant's thread. Nested course editors recheck actual ownership, protect upload validation and preserve array metadata; dynamically mounted lesson editors initialize from dashboard JavaScript. Course/account deletion refuses linked historical learning, financial and issued credential records before destructive side effects. Affiliate settlement matches the original locked course debit and split snapshot, records replay-safe exact commissions and reports net course revenue. Real banners, factual templates, browser-confirmed clipboard outcomes and populated report downloads replace disconnected controls. Public marketplace details mount their actual published Livewire records.
